# 二、Python变量

## 1. 什么是变量

变量就是给数据起一个名字。

例如：

```python
收入 = 200000
成本 = 120000
````

其中：

收入、成本是变量名。

200000、120000是保存的数据。

类似 Excel：

给单元格设置业务含义。

---

# 三、利用Python完成财务计算

## 1. 利润计算

财务公式：

利润 = 收入 - 成本

Python代码：

```python
收入 = 200000
成本 = 120000

利润 = 收入 - 成本

print("收入：",收入)
print("成本：",成本)
print("利润：",利润)
```

运行结果：

```
收入： 200000
成本： 120000
利润： 80000
```

---

## 2. 利润率计算

财务公式：

利润率 = 利润 ÷ 收入

Python代码：

```python
利润率 = 利润 / 收入

print("利润率：",format(利润率,".2%"))
```

运行结果：

```
利润率：40.00%
```

说明：

format()可以帮助Python输出百分比格式。

---

# 四、Python列表 List

## 1. 什么是列表

列表用于保存一组数据。

例如：

```python
部门费用=[
    10000,
    20000,
    30000
]

print(sum(部门费用))
```

运行结果：

```
60000
```

对应财务场景：

多个部门费用汇总。

类似Excel：

SUM函数。

---

# 五、Python字典 Dictionary

## 1. 什么是字典

字典可以保存：

“名称 + 数据”

结构。

类似财务报表：

| 项目   |      金额 |
| ---- | ------: |
| 营业收入 | 1000000 |
| 营业成本 |  600000 |
| 费用   |  300000 |

Python表示：

```python
财务数据 = {
    "营业收入":1000000,
    "营业成本":600000,
    "费用":300000
}
```

---

## 2. 查看全部数据

```python
print(财务数据)
```

结果：

```
{
'营业收入':1000000,
'营业成本':600000,
'费用':300000
}
```

---

## 3. 获取指定数据

代码：

```python
print(财务数据["营业收入"])
```

结果：

```
1000000
```

说明：

Python可以根据项目名称直接找到对应金额。
