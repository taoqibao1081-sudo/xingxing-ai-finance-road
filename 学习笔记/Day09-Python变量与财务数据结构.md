# 二、Python变量

变量可以理解为：

> 给数据起一个名字，方便后续调用。

例如：

```python
收入 = 200000
成本 = 120000

利润 = 收入 - 成本

print("收入：",收入)
print("成本：",成本)
print("利润：",利润)
```

运行结果：

```
收入：200000
成本：120000
利润：80000
```

财务含义：

收入、成本、利润已经成为 Python 可以计算的数据。

---

# 三、利润率计算

公式：

利润率 = 利润 ÷ 收入

Python代码：

```python
利润率 = 利润 / 收入

print("利润率：",format(利润率,".2%"))
```

输出：

```
利润率：40.00%
```

说明：

Python 可以自动完成财务指标计算。

---

# 四、列表 List

列表用于保存多个数据。

例如：

```python
部门费用 = [10000,20000,30000]

print(sum(部门费用))
```

输出：

```
60000
```

财务应用：

可以保存：

* 各部门费用
* 月度销售数据
* 产品收入数据

例如：

```python
1月收入
2月收入
3月收入
```

以后可以批量分析。

---

# 五、字典 Dictionary（重点）

字典非常适合保存财务数据。

格式：

```python
名称 = {
    "指标":数据
}
```

例如：

```python
财务数据 = {
    "营业收入":1000000,
    "营业成本":600000,
    "费用":300000
}

print(财务数据)
```

结果：

```
{
'营业收入':1000000,
'营业成本':600000,
'费用':300000
}
```

## 六、读取字典中的数据

例如读取营业收入：

```python
print(财务数据["营业收入"])
```

输出：

```
1000000
```

财务意义：

相当于 Excel：

| 指标   |      金额 |
| ---- | ------: |
| 营业收入 | 1000000 |
| 营业成本 |  600000 |
| 费用   |  300000 |

Python可以通过字段名称直接读取。

# 七、利润率自动计算

代码：

```python
财务数据 = {
    "营业收入":1000000,
    "营业成本":600000,
    "费用":300000
}


毛利 = 财务数据["营业收入"] - 财务数据["营业成本"]

毛利率 = 毛利 / 财务数据["营业收入"]

print("毛利率：",format(毛利率,".2%"))
```

输出：

```
毛利率：40.00%
```

---

# 八、费用率计算

公式：

费用率 = 费用 ÷ 营业收入

代码：

```python
费用率 = 财务数据["费用"] / 财务数据["营业收入"]

print("费用率：",format(费用率,".2%"))
```

输出：

```
费用率：30.00%
```
