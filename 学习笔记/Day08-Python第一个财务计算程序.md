# 三、Python基础知识

## 1. 创建变量

Python可以通过变量保存数据。

示例：

```python
收入 = 1004986.12

成本 = 603921.40
```

其中：

* 收入保存营业收入数据
* 成本保存营业成本数据

---

## 2. 财务指标计算

毛利公式：

```
毛利 = 收入 - 成本
```

毛利率公式：

```
毛利率 = 毛利 ÷ 收入
```

对应Python代码：

```python
毛利 = 收入 - 成本

毛利率 = 毛利 / 收入
```

---

# 四、完整代码实践

```python
收入 = 1004986.12

成本 = 603921.40


毛利 = 收入 - 成本

毛利率 = 毛利 / 收入


print("营业收入：",round(收入/10000,2),"万元")

print("营业成本：",round(成本/10000,2),"万元")

print("毛利：",round(毛利/10000,2),"万元")

print("毛利率：",format(毛利率,".2%"))
```
