# 二、Python 条件判断基础

## 1. if语句结构

Python 使用 if 判断条件：

```python
if 条件:
    执行代码
````

注意：

Python 使用缩进表示代码层级关系。

例如：

```python
if 毛利率 < 0.30:
    print("毛利率偏低")
```

表示：

如果毛利率低于30%，执行下面的提示。

---

# 三、else分支

当 if 条件不成立时，执行 else：

```python
if 条件:
    执行A
else:
    执行B
```

例如：

```python
if 毛利率 < 0.30:
    print("毛利率偏低")
else:
    print("毛利率正常")
```

逻辑：

如果毛利率低于30%：

输出风险提示

否则：

输出正常提示

# 四、财务指标自动计算

## 1. 毛利计算

公式：

毛利 = 收入 - 成本

Python代码：

```python
收入 = 1000000
成本 = 750000

毛利 = 收入 - 成本

print(毛利)
```

输出：

```
250000
```

---

## 2. 毛利率计算

公式：

毛利率 = 毛利 ÷ 收入

代码：

```python
毛利率 = 毛利 / 收入

print(format(毛利率,".2%"))
```

输出：

```
25.00%
```

---

## 3. 费用率计算

公式：

费用率 = 费用 ÷ 收入

代码：

```python
费用 = 400000

费用率 = 费用 / 收入

print(format(费用率,".2%"))
```

# 五、利用if实现财务预警

## 1. 毛利率风险判断

```python
if 毛利率 < 0.30:
    print("⚠ 毛利率偏低，需要关注盈利能力")
else:
    print("✓ 毛利率正常")
```

财务意义：

当毛利率低于30%，提示：

* 产品盈利能力下降
* 成本可能上涨
* 产品结构需要关注

---

## 2. 费用率风险判断

```python
if 费用率 > 0.30:
    print("⚠ 费用率偏高，需要关注费用控制")
else:
    print("✓ 费用率正常")
```

财务意义：

费用率过高可能说明：

* 管理费用增长
* 销售投入增加
* 经营效率下降

---

# 六、多条件判断

## or逻辑

or表示：

两个条件满足一个即可。

例如：

```python
if 毛利率 < 0.30 or 费用率 > 0.35:
    print("⚠ 本期经营存在风险，需要重点关注")
```

逻辑：

如果：

毛利率低于30%

或者：

费用率高于35%

则提示经营风险。

# 七、完整经营分析案例

```python
收入 = 1000000
成本 = 750000
费用 = 400000


毛利 = 收入 - 成本

毛利率 = 毛利 / 收入

费用率 = 费用 / 收入


print("毛利率：",format(毛利率,".2%"))
print("费用率：",format(费用率,".2%"))


if 毛利率 < 0.30:
    print("⚠ 毛利率偏低，需要关注盈利能力")
else:
    print("✓ 毛利率正常")


if 费用率 > 0.30:
    print("⚠ 费用率偏高，需要关注费用控制")
else:
    print("✓ 费用率正常")


if 毛利率 < 0.30 or 费用率 > 0.35:
    print("⚠ 本期经营存在风险，需要重点关注")
```
